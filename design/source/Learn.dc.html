DNS turns names into numbers

Computers find each other using numbers called IP addresses. DNS is the system that looks up the number for a name like example.com, so you never have to remember it.

Think of a phone book. You know your friend's name, and the book gives you their phone number. DNS is the phone book of the internet: you give it a name, it gives back a number.

Your device asks a resolver, which queries name servers for a record. An A record maps a hostname to an IPv4 address; AAAA maps it to IPv6. Answers are cached for a time set by the TTL.
